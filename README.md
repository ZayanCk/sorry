# I'm Sorry, Ruhma

A heartfelt interactive apology website with smooth animations, timed text reveals, and accompanying music.

## Features

- **Interactive Experience**: Click anywhere to begin
- **Timed Animations**: Text appears in sequence with smooth transitions
- **Background Music**: Ambient music that fades in smoothly
- **Responsive Design**: Works beautifully on desktop and mobile devices
- **Final Screen**: A poignant closing message

## View the Website

This website is hosted on GitHub Pages. Visit it here:
[https://ZayanCk.github.io/sorry/](https://ZayanCk.github.io/sorry/)

## How to Use

1. Open `index.html` in a web browser
2. Click anywhere on the screen to start
3. Enjoy the experience as the story unfolds
